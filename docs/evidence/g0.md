Forerunner 165 ve iPhone sonuçları olmadan G0 tamamlandı kabul edilmez.

“KISMİ” toplu POC durumudur; her alt deney yukarıda ayrı açıklanır. NOT RUN hiçbir
zaman PASS sayılmaz. Sentetik PNG boyutları (yaklaşık 0.8–1 KiB) gerçek harita
büyüklüğü veya bant genişliği için tahmin olarak kullanılamaz. Yerel HTTP süreleri
Garmin aktarım p95’i veya NFR12 yük testi değildir.

Görsel inceleme sırasında Mac kilitliydi. Kullanıcı eve döndüğünde kilidi açacağını
belirtti. Komut satırı simülatör testleri çalıştırıldı; ekran görüntüsüne bakılmış
veya fiziksel cihaz görülmüş gibi bir kanıt oluşturulmadı.

Başlangıçta bulunan ve düzeltilen hatalar: String karşılaştırmalarında nesne
eşitliği yerine içerik eşitliği; modelde olmayan drawScaledBitmap; kalıcı ağ
hatasının kamera hareketiyle sıfırlanması; non-ASCII imzada TypeError.
Geri dönüş testleri bunları kapsar. İlk simülatör bağlantısı açılış hazır olmadan
denendiğinde başarısız oldu; süreç açıldıktan sonra test bağlantısı kuruldu.

Temiz kaynak doğrulaması: ZIP farklı geçici klasöre açıldı, mevcut Python 3.14 ile
yeni `.venv` oluşturuldu, kilitler ağdan yeniden kuruldu. `make test` 49/49 ve
`CIQ_SDK_HOME=... make build-watch` PASS. Proje içi `.local` olmadan yeni anahtar
üretildi; imza anahtarı farklı olduğundan PRG SHA256’sının farklı olması beklenir.
İki kopyanın saat kaynak SHA256’sı eşleşir. Python 3.9’ın erken ve açıklayıcı
biçimde reddedilmesi ayrıca kontrol edildi.
